# CHANGELOG

## v0.1.0（2026-08-12）

- 初始版本：快速验证功能的"注入-验证"闭环（理解诉求 → 注入 → 编译 → 页面 → 取数 → 收敛）
- 注入手段选择矩阵：快捷入口 / mock 数据 / 硬编码 / console.log 埋点，优先最小侵入
- 注入代码打标规范：单行埋点 `[quick-start][<context>]` 前缀，多行代码块 begin/end 标记对
- 可逆性原则：注入局部可逆，收尾按标记精确清除并 grep 验证零残留
- 硬性限额 Read ≤ 5 / Grep ≤ 10；无收敛保护（连续 3 轮无新信息停下报告）
- 依赖浏览器控制 MCP（软依赖，缺失降级为手动复现模式）
