# CHANGELOG

## v0.3.0（2026-09-07）

- **复现方式默认反转**：AI 自动复现不再默认，改为**人工复现为主**——AI 保留打开/刷新页面 + read console 自动取数，用户按操作清单手动复现、回复确认词；AI 自动复现降为"用户明确要求时的可选加速"（仅限简单步骤）。修复实测问题"playwright 自动复现特别慢（全量快照逐步骤累计）且频繁操作错误（丰富 DOM 下 ref 误选），不如人工复现迅速无卡点"
- **自动复现成本约束**（保留可选模式时的优化）：快照最小化（复用首次 snapshot 的 ref，不为每步做全量快照）、确认最小化（操作后看页面状态或 console 变化即可）、尝试 2 次未触达立即降级人工
- **埋点透明化**：步骤 2 插入埋点后强制公告明细（`文件:行号 | context | 采集变量` + 示例代码），用户可打开文件核对、在 DevTools 自行观察；步骤 5 同步给出人工查看口诀（F12 / Ctrl+Shift+J → Console → 过滤 `live-debugger`），用户看到的日志与 AI 读取结果互证；步骤 6 收尾清除后公告清除范围。修复实测问题"AI 能读到埋点但人工无法确认埋点位置"
- 核心哲学更新：复现默认人工（人工最快最稳、无卡点，自动化按需）；description 与 README 同步更新

## v0.2.0（2026-09-01）

- **AI 自动复现**：复现环节改为 AI 通过浏览器 MCP 自动执行优先（Playwright 为首选：无障碍快照 + ref 确定性交互，省 token），人工复现降级为兜底。每次修 bug 不再强制等用户手动操作页面
- **bug 信息三要素**：前置阶段明确要求"复现步骤、现状（问题）、预期"三要素，缺哪项问哪项；"预期"成为闭环收敛基准（复现后数据与预期相符 = 问题解决）
- **复现步骤分层**：简单步骤（导航/点击/输入）AI 自动执行；复杂步骤（登录态/验证码/文件上传/多步业务流）请求用户描述清楚或直接交回人工；未提供时 AI 基于代码疑点推断最简路径尝试
- **受阻显式降级**：自动复现受阻（尝试 2 次未触达/自动化覆盖不了的操作）必须明确告知用户并请求二选一：补充复现步骤重试，或交回人工复现。不允许静默跳过复现
- **闭环新增人工最终确认**：AI 自动复现通过 ≠ 修复完成——自动复现只覆盖描述路径，收尾前必须请用户亲自走一遍复现步骤确认
- **步骤 5 新增对照分支**：数据与预期一致但问题仍在 → 复现路径未覆盖问题场景，需换路径或补充触发条件
- 浏览器 MCP 优先级：playwright 优先，chrome-devtools / puppeteer 兜底；meta.json check 脚本补充扫描 settings.json（用户级 + 项目级）配置位置（修复"chome-devtools 配在 ~/.claude/settings.json 仍报未安装"），install 文案推荐 playwright

## v0.1.3（2026-08-21）

- 浏览器 tab 治理：navigate 打开 URL 时优先复用已有空白 tab，不另开新 tab；若 MCP 实现导致新开 tab（空白页未被复用），导航后检查 tab 列表并关闭多余空白 tab，只保留目标页面一个 tab。修复"打开空白页后再开 URL 导致空白页残留"的问题；排查中途换 URL 同样复用当前 tab，不累积 tab

## v0.1.2（2026-08-19）

- 修复默认 URL 不生效：原文"（未提供用默认值）"与"缺失则先询问"同一句并存导致歧义，模型倾向询问而非使用默认值。现明确 URL 为可选项：未提供直接打开默认地址并告知用户，永远不为此询问

## v0.1.1（2026-08-18）

- 明确核心哲学：埋点数据是主要信息来源，代码分析只服务于选埋点位置，禁止为建立理解而读代码
- 收紧硬性限额：Read ≤ 5 → ≤ 3、Grep ≤ 10 → ≤ 5，并禁止通读文件/深挖调用链/为确认理解而读码
- 编译等待策略改为"不等待"：最多检查一次编译输出 mtime，严禁反复检查与 sleep 等待，编译是否生效由埋点数据出现与否验证
- 浏览器验证强制化：打开/刷新浏览器为每轮必做动作，未执行不算完成一轮；找不到 MCP 工具时明确告知并询问，禁止静默降级

## v0.1.0（2026-08-12）

- 初始版本：模拟人工 debugger 六步排查流程（分析定位 → 埋点 → 编译 → 页面 → 取数 → 闭环）
- 埋点统一前缀 `[live-debugger][<context>]`，支持精确过滤与清除
- 硬性限额：Read ≤ 5 / Grep ≤ 10；无收敛保护（连续 3 轮无新信息停下报告）
- 依赖浏览器控制 MCP（软依赖，缺失降级为手动复现模式）
