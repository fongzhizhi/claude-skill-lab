# session-review

> 根据当前会话上下文（最高优先）与 git diff（补充核对）生成技术复盘报告，输出 markdown 代码块供直接复制归档。

AI 辅助编程会话结束时，把"这次任务为什么这么做、根因是什么、改了哪里"沉淀成一份可归档的复盘报告。执行 `/session-review`，即可拿到一份完整的 markdown 报告（背景 / 根因分析 / 解决方案 / 关键改动 / 验证与结果 / 经验与后续）。

## 功能

| 能力 | 说明 |
| --- | --- |
| 会话优先 | 以会话上下文为事实来源——即使改动未实施、git diff 为空或不全，也能照常生成报告 |
| diff 补全 | git diff 用于核对与补全"关键改动"部分，与会话冲突时以会话为准 |
| 根因归档 | 报告聚焦"为什么"（根因、方案取舍）而非代码细节，适合 bug 修复后的根因归档 |
| 单块输出 | 输出单个 `markdown` 代码块，直接复制即可粘贴为 .md 文件归档 |

## 信息优先级

1. **会话上下文**：任务描述、根因分析过程、方案决策与理由、改动说明、验证结果（最高优先，必做）
2. **git diff**：暂存区/工作区变更，用于补全与核对（无变更则跳过，不阻塞）
3. **命令参数**：执行 `/session-review` 时附带的链接或说明

## 前置依赖

无（依赖 Git 本身，Claude Code 环境自带）。

## 部署

```bash
lab deploy session-review
```

部署后，命令在 Claude Code 对话中以 `/session-review` 调用。

## 使用

```
/session-review
/session-review "复盘登录页超时 bug，来源 https://example.com/ticket/123"
```

输出为单个 markdown 代码块（含背景、根因分析、解决方案、关键改动、验证与结果等章节），直接复制归档。没有可复盘的内容时，命令会告知用户。
