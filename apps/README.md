# apps/

自研 GUI / 桌面应用目录。与 [clis/](../clis/)（自研 CLI 工具）并列，共同构成 **lab 模块体系之外的工具区**。

## 与 lab 模块的区别

|          | lab 模块（skills / commands / suites …） | apps/ 下的应用                  |
| -------- | ---------------------------------------- | ------------------------------- |
| 部署终点 | `~/.claude/<type>/` 下的文件             | 独立的安装包 / exe              |
| 构建     | 无构建，`dist/` 即成品                   | 各自独立构建链（Tauri、WPF 等） |
| lab CLI  | `claude-lab deploy/status/list` 管理     | **不感知**，不参与任何部署      |

`claude-lab` 只扫描 `manifest.json` 的 `types` 与 `suites/`，因此 `apps/` 天然不会被 `list`、`status`、`deploy --all` 触及。**不要**把 `apps` 加进 `manifest.json` 或 `lab/index.js` 的 `TYPES`——那会破坏「`dist/` 即 `~/.claude/` 镜像」这一核心不变量。

## 目录约定

```
apps/<name>/
  README.md            # 一句话定位 + 构建命令 + 数据来源
  package.json         # 各自的依赖与脚本（如需 Node 侧）
  src-tauri/           # Tauri 应用的 Rust 侧（示例）
  ...
```

- 每个应用自包含，依赖与构建命令写在应用自己的 `README.md` 里
- 产物（`target/`、`bundle/`、安装包）不入仓，由根 `.gitignore` 兜底
- 计划与设计文档仍放在 [project-docs/plans/](../project-docs/plans/)，与源码分离
