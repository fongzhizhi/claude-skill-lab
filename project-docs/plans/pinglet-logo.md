# Pinglet Logo 状态联动改造说明（纯静态版）

## 一、 设计理念：动静分离，极简纯粹

Logo 作为看板的视觉锚点，不再承担“动态报警”的功能。为了防止视觉疲劳和焦点冲突，我们将动效彻底剥离：
**窗口边缘的“呼吸灯”负责动态提醒，左上角的 Logo 只负责静态的状态映射。**
Logo 绝不闪烁，永远保持安静的常亮或暗淡。

## 二、 图形结构与颜色映射

基于原版“信号点 + 两道波纹”的几何结构，去除黑色圆底背景。三层图形分别映射到三种核心状态：

| 图形位置     | 映射状态 | 颜色 (默认暗色主题) | 视觉表现       |
| :----------- | :------- | :------------------ | :------------- |
| **中心圆点** | 进行中   | 绿 `#2ED573`        | 存在则静态点亮 |
| **内圈波纹** | 已中断   | 橙 `#FAAD14`        | 存在则静态点亮 |
| **外圈波纹** | 待处理   | 红 `#FF4D4F`        | 存在则静态点亮 |
| _(无)_       | 已完成   | -                   | 不点亮任何图形 |

## 三、 联动逻辑（无动画）

### 1. 未激活状态（当前无此状态）

- **样式**：保留对应状态色，仅降低透明度（`opacity: 0.5`）。
- **效果**：作为隐约的彩色轮廓融入背景，不抢夺视线。

### 2. 激活状态（当前存在此状态）

- **样式**：恢复 100% 原色，透明度设为 `1`，移除灰度。
- **效果**：静态高亮。不管有多少个待处理，红色外圈就静静地亮在那里，直到你处理完。

_注：Logo 的颜色变化不受设置面板中“呼吸灯”开关的影响，因为 Logo 本身不包含任何闪烁动画。_

## 五、 技术实现指引（给 AI 的提示）

```markdown
请更新前端左上角 SVG Logo 的状态联动逻辑。核心要求：**只做静态高亮，绝对不要任何闪烁、呼吸或 keyframes 动画。**

1. 基础样式：
   - 给三个 svg 元素加上默认类 `.inactive`：`opacity: 0.5; transition: opacity 0.3s;`

2. 激活样式：
   - 定义 `.active` 类：`opacity: 1;`

3. JS 状态判定逻辑（纯类名切换）：
   - 遍历当前所有会话。
   - 如果存在“待处理”：给 `#logo-pending` 加上 `.active`，否则移除。
   - 如果存在“已中断”：给 `#logo-interrupted` 加上 `.active`，否则移除。
   - 如果存在“进行中”：给 `#logo-running` 加上 `.active`，否则移除。
   - “已完成”状态不控制任何 Logo 元素。

4. 注意：无论用户是否在设置中开启了“呼吸灯”，Logo 均不得添加任何 animation，只允许使用过渡（transition）来实现颜色的平滑切换。
```
