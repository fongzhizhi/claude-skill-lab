# Pinglet 看板 UI 与功能设计定稿（v1.2）

> 核心设计哲学：极简、克制、安静、贴纸感。绝不臃肿，数据自动流转，用户绝对掌控。

## 一、 状态定义与文案（四种状态）

为了保持极简与统一，会话状态严格收敛为四种，文案统一为三字：

1. **待处理**：最高优先级，AI 停下来需要你介入（等待确认、权限请求等）。
2. **已中断**：会话异常退出、报错崩溃或被手动强行停止。
3. **进行中**：AI 正在思考、执行命令或正常运转。
4. **已完成**：上一轮任务结束，安静闲置，等待下一个 Prompt。

_排序逻辑_：`待处理` > `已中断` > `进行中` > `已完成`。

## 二、 主题与色彩规范（支持暗色/亮色）

颜色**不写死**，而是抽象为语义化的 CSS 变量，由主题（Theme）控制。

### 1. 暗色主题（默认）

- **背景**：深黑/深灰，不透明纯色（`#18181B`）；面板与 Tooltip 不使用背景模糊。
- **文字**：主标题白色/亮灰，副标题暗灰。
- **状态语义色**：
  - 待处理：亮红（如 `#FF4D4F`）
  - 已中断：琥珀橙（如 `#FAAD14`）
  - 进行中：霓虹绿（如 `#2ED573`）
  - 已完成：中灰（如 `#787878`）

### 2. 亮色主题

- **背景**：纯白（`#FFFFFF`），不透明纯色。
- **文字**：主标题深黑，副标题浅灰。
- **状态语义色**：为了在白底上清晰可见，颜色需稍微加深：
  - 待处理：深红（如 `#D93025`）
  - 已中断：深橙（如 `#D97706`）
  - 进行中：深绿（如 `#059669`）
  - 已完成：浅灰（如 `#9CA3AF`）

## 三、 界面布局与交互

### 1. 顶部标题栏 (Header)

- **左侧**：极简 Logo 图标。
- **左侧汇总（动态显示）**：
  - 按 待处理 > 已中断 > 进行中 的顺序显示数量非零的汇总。例如：`[ 1 待处理 ] [ 1 已中断 ] [ 3 进行中 ]`。
  - 文字颜色直接跟随该状态的颜色（如待处理是红字，已中断是橙字，进行中是绿字）。
  - 如果没有进行中会话且没有异常状态（只剩已完成），仅显示 Logo，不显示多余文字。
- **右侧图标组**（Hover 时微亮，平时安静）：
  - 📌 **图钉**：窗口始终置顶，图钉只切换顶栏是否可拖动。文案表示点击后进入的模式——拖动模式下显示「固定模式」，固定模式下显示「拖动模式」；亮起代表固定不可拖动，暗色代表可随意拖动。
  - ⚙️ **设置**：点击弹出/收起设置面板。
  - **关闭 / 最小化**：图标与文案跟随设置动态变化——开启「关闭时最小化到托盘」时显示最小化图标与「最小化」，关闭时显示 ✕ 与「退出」。
- **拖拽**：除按钮外的空白处，支持按住拖拽窗口；点击面板外的区域不会隐藏窗口。

### 2. 会话列表项 (Session Row)

- **排版**：双行布局。
  - 第一行：`[状态灯/状态字] [会话标题 (flex:1截断)] [时间状态]`。
  - 第二行：`[目录名] [环境标签]`，整体右对齐（目录在前，入口标签在后）。
- **会话标题**：单行显示，超出部分用 `...` 截断（CSS ellipsis）。标题优先取 `nameSource = "hook"` 的用户标题，其次读 transcript 中最后一条 `custom-title` / `ai-title`，仍无标题时显示目录名；不直接把内部 slug（如 `demo-alpha-3f`）当作标题。
- **目录名**：**只显示当前文件夹名**（如 `demo-alpha`），不显示完整路径；使用与入口标签一致的边框、圆角与字号。
- **环境标签**：如 `[vs-code]`、`[cli]`，统一小写，边框透明度极低，不抢视觉焦点。
- **标签配色**：目录按完整路径哈希稳定分配低饱和色板槽位（同目录同色、不同目录尽量不同色，容量 8 色循环复用）；入口标签固定三色——`vs-code` 蓝、`cli` 紫、其他中性色。色板随亮/暗主题切换，饱和度低于四态语义色；标签文字使用实色，不再整体降透明度以保证可读性。
- **悬浮 (Hover) 效果**：悬停约 1.5 秒后弹出轻量 Tooltip，展示完整路径、完整标题、更新时间等；标题与内部名不同时补充内部名，并展示会话 ID 便于区分同目录会话。底部提示「双击激活会话窗口」；避免划过时遮住会话行影响点击。双击会话行后立即收起，且不再弹出。
- **双击 (Double Click) 效果**：仅 `vs-code` / `cli` 入口支持。VSCode 会话打开目录并将已存在的 VSCode 窗口切到前台；CLI 会话若运行在 VSCode 集成终端中（按进程父链识别），激活对应的 VSCode 窗口，否则按启动目录或终端标题聚焦已有 Git Bash 窗口；匹配不到时行内闪烁并提示无法激活，不新开窗口；其他入口只做行内闪烁并提示不支持。底部提示保留约 2 秒。
- **无右键菜单**。

### 3. 底部心跳指示器 (Heartbeat)

- **位置**：右下角。
- **形态**：一个极小的纯色小圆点（无呼吸效果，不干扰视线）。
- **状态联动**：
  - 🟢 绿色：正常，正在实时接收数据。
  - 🟡 黄色：警告，超过一定时间（如 5 秒）未收到更新。
  - 🔴 红色：断开，长时间（如 15 秒）未收到更新。
- **悬浮效果**：Hover 时展示文字如 `最后更新于 01:26:46`。

## 四、 设置面板 (Settings Popover)

点击齿轮弹出的轻量悬浮卡片（不透明纯色背景），顶部提供「← 返回」按钮用于收起面板，包含以下配置：

### 1. 外观与提醒

- **默认配置**：暗色主题、开启呼吸灯与窗口抖动、关闭时最小化到托盘、拖动模式（窗口置顶、顶栏可拖动）、关闭鼠标穿透与开机自启。
- **主题**：暗色 / 亮色（单选）。
- **提醒模式**（多选逻辑）：
  - [ ] 呼吸灯（异常或完成时边框发光）
  - [ ] 音效（发出轻微提示音）
  - [ ] 窗口抖动（状态突变时窗口轻微抖动）
  - [ ] 无（互斥选项，选中此项时自动取消其他三项）
  - 勾选呼吸灯 / 音效 / 窗口抖动时立即演示对应效果，不选中不演示；演示时呼吸灯闪烁三次。
  - 触发分两档：`待处理 / 已中断` 的突变触发强提醒（呼吸灯用对应状态色闪烁三次，音效响一次，窗口抖动来回三次）；`进行中 → 已完成` 触发完成提醒（呼吸灯用进行中语义色（暗色 `#2ED573` / 亮色 `#059669`）闪烁一次，音效响一次，窗口抖动一次约 0.3 秒）。音效与抖动按各自开关。同一次轮询里异常优先，完成提示让位。

### 2. 系统与行为

- **开机自启**：Switch 开关。
- **关闭行为**：Switch 开关（开启则点击 X 时最小化到托盘，关闭则直接退出）。
- **鼠标穿透**：Switch 开关。开启后**等设置面板关闭再生效**，避免面板立刻无法点击；生效后窗口不接收鼠标事件，点击落到下方窗口。恢复方式：全局快捷键或托盘左键会先关闭穿透再显示 / 聚焦窗口，也可右键托盘图标 →「鼠标穿透」取消勾选。设置、托盘勾选与快捷键切换三方同步。
- **全局快捷键**：输入框，按下快捷键快速呼出/隐藏看板（如 `Alt+Shift+P`）。

### 3. 开发信息 (About)

- 显示应用版本号（如 `v1.2.0`）。
- 显示开发者信息（如 `Designed & Built by You`）。
- 提供项目主页或 GitHub 链接（可选）。

### 4. 底部

- `[恢复默认]` 按钮：一键恢复上述默认配置，并同步窗口置顶、关闭行为、鼠标穿透、开机自启与全局快捷键。
- `[退出应用]` 按钮。

## 五、 窗口行为与尺寸规范

- **尺寸**：宽度固定（`350px`），高度自适应（随列表行数撑开）。
- **最大高度**：限制在 `600px`（或屏幕高度 60%）。超出则列表内部出现滚动条。
- **滚动条**：默认隐藏，仅在列表实际滚动时短暂显示极细的（`4px`）圆角滚动条；鼠标划过会话行不触发。
- **置顶**：窗口始终置顶，点击面板外区域不会被其他窗口覆盖；图钉只控制顶栏能否拖动。
- **边缘吸附**：拖动到屏幕边缘约 10px 内时自动吸附；吸附后需向外拖动约 24px 才解除锁定，避免小步拖动被反复拉回边缘。
- **托盘菜单**：「显示」（勾选表示窗口当前可见，点击切换显隐）、「鼠标穿透」（勾选表示穿透中）、「设置」（显示窗口并打开设置面板，穿透中会先关闭穿透）、「退出」。
- **鼠标穿透**：设置面板关闭后生效，窗口忽略鼠标事件（Win32 `WS_EX_TRANSPARENT`）；托盘菜单与全局快捷键保持可操作，并作为恢复入口。

## 六、 AI 开发技术指引（给前端/Rust 开发者的 Prompt）

```markdown
请按照以下要求开发/修改 Tauri 2 应用的前端 UI 与交互：

1. 窗口属性 (Tauri 配置)：
   - width: 350, resizable: false
   - transparent: true, decorations: false（透明仅用于圆角，面板背景使用不透明纯色）
   - height: 自动适应 (fit_content), max_height: 600。
   - 开启 data-tauri-drag-region 用于拖拽。

2. 主题与 CSS 变量：
   - 使用 CSS 变量定义颜色：--color-bg, --color-text-main, --color-text-sub, --color-state-pending, --color-state-interrupted, --color-state-running, --color-state-done。
   - 根节点 data-theme="dark" 或 "light" 控制变量切换。

3. 列表布局 (Flexbox，双行)：
   - 第一行：左侧状态灯，状态字固定宽度，标题设 flex: 1 并省略号截断，右侧时间状态。
   - 第二行：文件夹名 + 环境标签，整体右对齐，两者共用标签样式。
   - 获取目录名使用 path.basename()。

4. 心跳与交互：
   - 右下角放一个 6px 的纯色 div 圆点（绿/黄/红），无动画。
   - 悬停 1.5 秒后用自定义 Tooltip 展示完整路径；移出立即隐藏。
   - 双击列表行触发 IPC 事件，通知 Rust 调用 Windows API 激活对应进程窗口。
```
