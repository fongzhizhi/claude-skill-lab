# Pinglet 看板 v1.3 增量改造说明

## 一、 窗口尺寸动态调整

抛弃固定尺寸，支持通过鼠标拖拽边缘调整窗口大小，并严格限制边界。

- **拖拽缩放**：由于是无边框窗口（`decorations: false`），在窗口四周预留 `5px` 的透明热区，触发系统级缩放。
- **尺寸硬限制**：
  - 宽度：最小 `280px`，最大 `600px`。
  - 高度：最小 `200px`，最大 `800px`。
- **高度自适应逻辑**：
  - 列表内容会撑开窗口高度；当内容减少时，窗口会自动收缩（不留多余空白）。
  - 当内容过多，超过用户当前拖拽设定的高度，或超过最大高度限制时，停止撑开窗口，列表内部出现极细滚动条（`4px`，Hover 时显示）。

## 二、 字号与图标联动适配

因为窗口尺寸可自由拉伸，为了保持视觉比例协调，新增字号控制。**不只是文字，界面上的 Logo、右上角操作图标、状态圆点也必须同比例联动缩放。**

- 在根节点定义 CSS 变量 `--font-size-base`。
- 提供三档字号设置：
  - **小**：`13px`
  - **标准**：`14px`（默认）
  - **大**：`15px`
- **全局元素联动规则**：
  - **Logo 与图标**（图钉、设置、关闭）：尺寸不再写死像素，而是跟随字号按比例放大。
  - **指示灯**（左侧状态圆点、右下角心跳点）：尺寸按字号的比例计算，防止字号变大后圆点显得像灰尘。
  - **点击热区**：图标放大后，按钮容器的 `padding` 也要相应撑大，防止点击困难。

## 三、 设置面板新增项

在设置弹窗中新增以下功能：

1. **字号调整**：小 / 标准 / 大（单选）。
2. **恢复默认**：一个重置按钮，点击后一键清空本地存储的所有用户偏好配置，包括：
   - 宽高恢复为默认尺寸（宽 `280px`，高度上限 `400px`）。
   - 字号恢复为“标准”。
   - 主题恢复为默认主题。
   - 提醒模式等设置恢复默认。

## 四、 技术实现指引（给 AI 的提示）

```markdown
请针对当前的 Tauri 2 应用进行以下前端和配置更新：

1. 窗口配置 (`tauri.conf.json`)：
   - 修改 `resizable: true`。
   - 设置 `minWidth: 280, maxWidth: 600`。
   - 设置 `minHeight: 200, maxHeight: 800`。
   - 保持 `decorations: false` 和 `transparent: true`。

2. 边缘拖拽热区实现：
   - 在前端用 CSS 绘制上下左右及四个角的透明 div（宽/高 5px，绝对定位并设置 z-index）。
   - 监听 `mousedown` 事件，调用 Tauri API `getCurrentWindow().startResizeDragging('方向')`（方向包括 'e', 'w', 's', 'n', 'se', 'sw', 'ne', 'nw'）。

3. 高度自适应与滚动条：
   - 主容器高度设为 `fit-content`。
   - 列表容器设置 `flex: 1` 且 `overflow-y: auto`。
   - 编写细线滚动条样式，默认隐藏，`&:hover::-webkit-scrollbar` 时显示 `4px` 宽度。

4. 字号联动、图标缩放与持久化：
   - 定义 CSS 根变量 `--font-size-base`，默认 `14px`。
   - **禁止对 UI 图标（Logo、右上角按钮）和状态圆点写死 `px` 尺寸**。
     - 图标宽高设为 `1em` 或 `1.2em`；
     - 状态圆点/心跳点设为 `calc(var(--font-size-base) * 0.45)`；
     - 按钮的 `padding` 随之适配，保证点击热区。
   - 设置面板加入字号切换（13px / 14px / 15px），写入 `localStorage` 并在加载时读取应用。
   - 设置面板加入“恢复默认”按钮，点击清除 `localStorage`，重置窗口宽高为 `280px` / 高度上限 `400px` 并刷新页面。
```
